## 团队规模

4 人。产品负责人主要负责产品设计、需求标准、交互定义、优先级与验收；其他成员协作补全知识点和题库数据库，并使用现有 AI 出题软件、知识点软件提高生产效率。

## 建议分工

| 角色 | 主责 | 交付物 |
|---|---|---|
| 产品负责人 | 产品定义、PRD、交互流程、AI 组件规范、验收与 Demo | 产品文档、原型、验收记录 |
| 成员 A | 知识体系 | 章节树、知识点、前置关系 |
| 成员 B | 题库内容 | 真题/改编/原创题、答案、解析、标签 |
| 成员 C | 数据生产与质量 | 数据导入、去重、格式校验、质量报告 |

以上是建议分工，实际人员由团队确认。

## 协作规则

- 先统一 Schema，再批量生产数据。
- 每批数据必须经过自动校验和人工抽检。
- 题目与知识点引用必须使用 ID，不使用自由文本作为唯一关联。
- 每周同步一次进度、阻塞项和数据质量问题。
- 所有需求变更更新 PRD 或决策记录。
- 每项任务必须有负责人、截止时间和验收条件。
