# 15 产品路线图

## 阶段 0：产品与数据标准（当前）

交付：
- 产品定位和 PRD 初稿。
- 核心用户流程。
- Lumi 行为与交互组件规范。
- 知识点和题目数据标准。
- MVP 验收标准。

退出条件：四人对 MVP 范围、数据字段和核心 Demo 达成一致。

## 阶段 1：垂直切片

围绕一个高数薄弱点，打通：
- 题目呈现。
- 用户作答与画板。
- 事件回传。
- Lumi 分析。
- 针对性追问。
- 画像更新。

退出条件：端到端流程可重复运行。

## 阶段 2：MVP 核心闭环

补齐：
- 初始诊断。
- 核心知识点资源。
- 错题本。
- 基础 Dashboard。
- 专项训练。
- 学习报告。
- Mock Demo。

退出条件：达到 P2 体验和稳定性目标。

## 阶段 3：比赛强化与扩展

时间允许时：
- 简化模拟考试完善。
- 更多图表与知识图谱交互。
- 语音能力。
- 更广知识点覆盖。
- 更完善的学习趋势和主动建议。

## 阶段 4：后续产品化

- 多学科与多考试类型。
- 更完整的离线体验。
- 社区贡献和资源版本生态。
- 多 Agent 拆分（经实际需要验证后）。
- 更严格的学习效果评估。

## P2 / P3 定义

- P2：核心功能完整、UI/UX 精致、交互流畅、Demo 稳定。
- P3：功能更丰富、知识覆盖更完整、生态能力增强。P3 不得挤占 P2 核心闭环质量。
