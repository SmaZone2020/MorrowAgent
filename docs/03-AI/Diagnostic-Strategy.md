# 09 智能诊断与教学策略规范

## 1. 诊断目标

从“题目答错”进一步定位到“哪个知识点、哪类错误、哪种能力存在问题”，并验证可能的根本原因。

## 2. 诊断粒度

- 具体知识点。
- 错误类型。
- 能力维度。

错误类型建议：
- 概念理解。
- 公式或定理使用。
- 计算失误。
- 逻辑推理。
- 方法选择。
- 审题理解。
- 知识迁移。
- 表达或步骤不完整。

## 3. 多轮诊断流程

1. 覆盖性基础测评。
2. 对疑似薄弱点追问。
3. 使用变式题验证迁移能力。
4. 生成诊断报告。
5. 用户确认或修正结论。

并非所有用户都必须走完所有轮次；可根据证据、时间和用户意愿动态终止或追加。

## 4. 根因推断

示例：

```text
导数定义题失败
  ↓（推测）
函数极限概念不清
  ↓（推测）
左右极限理解不完整
  ↓（验证题）
确认 / 排除该假设
```

知识依赖链应区分：
- 课程体系中的正式前置关系。
- AI 根据本次行为推断出的可能原因。

二者不能混为一谈。

## 5. 教学策略选择

根据诊断结果选择：
- 直接解释。
- 苏格拉底式引导。
- 前置知识补充。
- 例题拆解。
- 变式训练。
- 综合训练。
- 延迟复习。

教学风格可由用户设置，并根据学习反馈调整。

## 6. 训练优先级

长期方向是由算法量化排序，AI 负责解释与动态调整。候选因素：
- 知识点重要程度。
- 当前掌握度与置信度。
- 前置依赖影响。
- 错误频率和近期性。
- 距离考试的时间。
- 用户目标与可用学习时间。

权重和公式待试点数据与团队评审后确定。

## 7. 效果验证

不能只以原题答对作为掌握证据。建议使用：
- 同知识点不同表述题。
- 变式题。
- 独立完成。
- 延迟复测。

记录训练前后表现，避免没有证据就宣称学习效果。
