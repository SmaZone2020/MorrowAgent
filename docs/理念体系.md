## 总体定位

**项目名称：** Morrow Agent
**项目定位：** 面向自主学习的开放式 AI 教育智能体。
**核心使命：** 推动优质教育资源普惠化，把自学的能力还给每一个人。
**长期愿景：** 构建开放、普惠、可持续演进的 AI 学习生态。

Morrow Agent 不只是「接入大语言模型的智能高数辅导软件」，而是以 AI Agent 为核心，围绕学习者持续建模、知识诊断、个性化教学和学习效果验证构建的新一代 AI Native 学习系统。

## 理念体系

### 1. 教育理念：教育公平与优质资源普惠化

教育公平是 Morrow Agent 最宏大的社会价值来源。

当前，教育资源仍存在显著不平等：

- 部分学习者可以负担一对一家教，部分学习者只能依赖录播课程；
- 部分学习者遇到问题可以随时请教优秀教师，部分学习者只能自行搜索答案；
- 部分学习者拥有丰富的学习资源和指导，部分学习者甚至无法准确判断自己的知识盲区。

传统教育资源的分配受地域、家庭经济条件、师资力量等因素影响。AI 有机会改变这一状况。

Morrow Agent 希望让每一个学生，无论来自何种学校、地区或家庭，都能获得持续、个性化的学习指导。

在中文语境中，可将这一理念表述为：

> **优质教育资源普惠化。**

其对应的英文概念为：

> **Democratization of Education / Education Equity**

该理念强调的不只是技术应用，而是教育机会与学习支持的可及性。

---

### 2. 学习理念：从知识灌输到自主学习

自主学习是 Morrow Agent 最重要的教育理念。

传统教育往往遵循如下路径：

```text
老师讲授 → 学生听课 → 学生做题 → 考试评价
```

通用 AI 往往遵循如下路径：

```text
学生提问 → AI 回答 → 学生获得答案
```

Morrow Agent 希望建立的学习闭环是：

```text
理解学习者
    ↓
发现知识盲区
    ↓
追溯根本原因
    ↓
个性化教学
    ↓
针对性训练
    ↓
验证真实掌握
    ↓
培养独立学习能力
```

其核心原则可表述为：

> **AI 不应该让学生越来越依赖 AI，而应该让学生逐渐拥有不依赖 AI 的能力。**

该原则应成为 Morrow Agent 的产品设计原则：AI 的价值不在于替代学生思考，而在于帮助学生形成可迁移、可持续的自主学习能力。

---

### 3. 产品与技术理念：AI Native Education

AI Native Education 是 Morrow Agent 在技术与产品层面最值得强调的理念。

传统教育软件通常将 AI 作为附加功能，例如：

- AI 答疑；
- AI 出题；
- AI 生成解析。

Morrow Agent 的 AI Native 路径则是从底层重新设计学习系统，使 AI Agent 成为理解学习者、组织学习过程、调用交互组件并验证学习效果的核心。

| 传统教育软件 | Morrow Agent |
| --- | --- |
| 用户主动寻找功能 | Agent 理解用户意图 |
| 固定课程路径 | 动态学习路径 |
| 固定题目推荐 | 基于知识画像的训练 |
| 记录答题正确率 | 分析解题思路和根本错误 |
| 记录学习历史 | 长期学习记忆 |
| 静态 UI | AI 可生成、更新的交互工作台 |
| 统一教学内容 | 个性化教学策略 |

其中，AI Interactive Workspace 是重要产品载体。它不只是聊天窗口，而是让 AI 可以调用题目卡片、公式编辑器、手写画板、函数图像、知识图谱等交互组件；用户的操作又会结构化地反馈给 AI。

这一探索对应的重要技术方向是：

> **Human-AI Collaborative Learning Environment（人机协同学习环境）**

其目标不是让 AI 单方面输出答案，而是构建人与 AI 协同完成理解、练习、诊断与验证的学习环境。

### 4. 品牌哲学：每个人都有无限可能

每个人都有无限可能，是 Morrow Agent 最具人文价值的理念。

我们认为：一个人的潜力不应只由过去的成绩决定。曾经被认为学习不佳的人，也可能通过编程发现自己的创造力，参与复杂软件开发和开源协作，并与世界各地的开发者共同工作。

Morrow Agent 希望让更多学生发现：

> 他们也有学习和成长的可能。

品牌哲学可凝练为：

> **过去的成绩，不应该定义未来的可能性。**
> **Your past performance does not define your future potential.**

## 实施与表达

Morrow Agent 在理念表达与产品落地之间应始终坚持以下原则：

1. **愿景可以面向未来十年，产品必须解决今天的问题。**
   宏大理念必须由可演示、可验证的产品闭环支撑。

2. **以完整学习闭环证明价值。**
   比赛与路演中，不应只讲教育普惠、AI Native、开放生态等宏大概念，而应让评审看到完整过程：一个学生做错一道极限题，Lumi 发现其真正不理解的是无穷小量，随后进行教学、训练、变式验证，最终确认学生能够独立解决问题。

3. **以真实效果支撑理念。**
   一个完整、可信、可验证的学习过程，比十个宏大概念更具说服力。

4. **以开放但审慎的态度建设生态。**
   MLPS 与开放学习生态应以独立实现、第三方使用和社区参与为验证标准，避免以规范发布替代生态形成。
