# 待确认事项

> 记录现有文档与讨论中**尚未定案**的点。任何未在此处或 `docs/DECISIONS.md` 中确认的细节，都不得被当作已确认需求。

## 使用方式

- 新增问题：写明背景、可选方案、影响面、建议结论。
- 结案：把结论移入 `docs/DECISIONS.md` 并在本条标注 `已结案 → D-xxx`。
- 状态取值：`待确认` / `调研中` / `已结案` / `不处理`。

---

## Q-001 知识库 ID 最终规则

- 状态：已结案 → D-053 附带的 `prompts/conventions.md` 第 2 节
- 结论：沿用 `math_higher_{章节 slug}_{snake_case}`，题目 `math_higher_q_{6 位数字}`，真题登记 `math_higher_exam_{年份}_{地区}_{卷别}`；发布后 ID 不得修改。

## Q-002 难度标尺的量化定义

- 状态：已结案 → D-053
- 结论：题目难度按目标人群正确率区间标定（`[85%,100%]` / `[70%,85%)` / `[55%,70%)` / `[40%,55%)` / `[0%,40%)`）；知识点难度按认知负荷标定。两者都强制填写 `difficulty_basis`。细则见 `prompts/conventions.md` 第 3 节。

## Q-003 真题收录的版权边界

- 状态：已结案 → D-054
- 结论：授权不明的真题只登记元数据与链接，不收录题干原文。题库引用真题必须先登记 `exam_sources`，且仅 `license: public_domain` 的登记项可被引用；校验脚本强制拦截。

## Q-004 Provider 密钥的加密方案

- 状态：已结案 → D-046
- 结论：Windows 用 DPAPI 加密整条配置落盘，Android 后续接 Keystore；非 Windows 显式报错，不做明文降级。

## Q-005 笔迹文件格式

- 状态：已结案 → D-052
- 结论：自研笔画流 JSON，带格式版本号，支持回放与增量保存；不存位图快照。

## Q-006 Android 端窗口规范是否复用桌面自绘标题栏

- 状态：待确认
- 背景：D-042 只覆盖 Windows 无边框窗口。
- 影响：移动端安全区域与返回手势的适配成本。
- 建议：移动端使用系统栏，不复用自绘标题栏。

## Q-007 知识包「跟随最新版」的冲突策略

- 状态：待确认
- 背景：已决定支持锁定/跟随最新版（D-036）。
- 可选方案：静默升级并保留旧版本快照；或提示用户确认。
- 影响：学习记录与旧版本知识点的关联稳定性。
- 建议：升级时保留旧 ID 映射表，不中断历史关联。

## Q-008 掌握度 0-100 与置信度的计算口径

- 状态：已结案 → D-056
- 结论：掌握度 = 难度加权正确率 + 时间衰减，并附 Lumi 带证据的评述；分数必须可追溯到具体作答记录。权重与半衰期细节在实现时定稿并记录到决策表。
- 现状：知识画像页仍只显示作答次数与正确率，待算法落地后替换。

## Q-009 答题后的自动推进规则

- 状态：已结案 → D-055
- 结论：答对自动跳下一题，答错停留在解析；不做成设置项。
