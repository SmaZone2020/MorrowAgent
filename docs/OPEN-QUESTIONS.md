# 待确认事项

> 记录现有文档与讨论中**尚未定案**的点。任何未在此处或 `docs/DECISIONS.md` 中确认的细节，都不得被当作已确认需求。

## 使用方式

- 新增问题：写明背景、可选方案、影响面、建议结论。
- 结案：把结论移入 `docs/DECISIONS.md` 并在本条标注 `已结案 → D-xxx`。
- 状态取值：`待确认` / `调研中` / `已结案` / `不处理`。

---

## Q-001 知识库 ID 最终规则

- 状态：待确认
- 背景：`Knowledge-Standard.md` 只给出格式建议，`prompts/` 与 `schemas/` 目前按该建议实现。
- 可选方案：沿用 `math_higher_{chapter}_{slug}`；或引入更短的分层 ID。
- 影响：知识点重命名成本、跨版本引用稳定性。
- 建议：沿用现状，先在 MVP 冻结。

## Q-002 难度标尺的量化定义

- 状态：待确认
- 背景：`difficulty` 只有五档枚举，没有可执行的判定标准。
- 可选方案：按解题步骤数 + 需要的知识点数量打分；或按目标人群正确率区间标定。
- 影响：AI 自动标注的一致性、诊断难度匹配。
- 建议：MVP 先按正确率区间标定，后续再用数据校准。

## Q-003 真题收录的版权边界

- 状态：待确认
- 背景：陕西专升本真题的再分发授权不明确。
- 影响：`Morrow-Knowledge` 能否直接收录题干全文。
- 建议：默认只记录元数据与链接，正文需授权后再入库（对应 D-042 精神）。

## Q-004 Provider 密钥的加密方案

- 状态：调研中
- 背景：已决定 API Key 本地加密存储（D-032），未定具体密钥来源。
- 可选方案：Windows DPAPI / Tauri Stronghold / 系统钥匙串。
- 影响：安全性与跨端一致性（Windows + Android）。
- 建议：Windows 用 DPAPI，Android 用 Keystore，抽象为统一接口。

## Q-005 笔迹文件格式

- 状态：待确认
- 背景：已决定笔迹存独立文件（D-033），未定格式。
- 可选方案：自研 JSON 笔画流；或兼容常见手写格式。
- 影响：回放、缩放清晰度、体积。
- 建议：笔画流 JSON + 版本字段，便于回放与增量保存。

## Q-006 Android 端窗口规范是否复用桌面自绘标题栏

- 状态：待确认
- 背景：D-043 只覆盖 Windows 无边框窗口。
- 影响：移动端安全区域与返回手势的适配成本。
- 建议：移动端使用系统栏，不复用自绘标题栏。

## Q-007 知识包「跟随最新版」的冲突策略

- 状态：待确认
- 背景：已决定支持锁定/跟随最新版（D-034）。
- 可选方案：静默升级并保留旧版本快照；或提示用户确认。
- 影响：学习记录与旧版本知识点的关联稳定性。
- 建议：升级时保留旧 ID 映射表，不中断历史关联。
