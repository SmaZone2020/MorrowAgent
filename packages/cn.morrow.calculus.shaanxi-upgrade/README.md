# 高等数学（陕西专升本）

覆盖高等数学完整教材的学习包：从函数与极限到曲线曲面积分共十章，另附公式速查、考点总结、向量代数与空间解析几何，以及陕西专升本历年真题。

## 目录

- `manifest.yaml` 学习包入口，客户端只读它来定位内容
- `knowledge/` 章节树与知识点 Markdown 正文
- `questions/` 按来源类型分组的题库
- `media/` 正文配图与封面
- `taxonomy/` 标签与错误类型
- `citations/` 资料来源与授权状态

## 内容来源

第一至第十章正文与配图来自《高数笔记文字版》（CC BY-SA 4.0，据北京邮电大学《高等数学（第 2 版）》整理），按协议要求署名并以相同协议共享。附录与精讲章节来自用户自备笔记，仅限本机使用。

历年真题为用户自行持有的扫描件录入，`citations/sources.yaml` 中登记为 `local_only`：**本学习包仅限本机使用，不得公开分发。**

## 使用

在 Morrow Agent 的书架上通过「导入学习包」选择 `.morrow` 文件，或在开发时直接指向本目录。
